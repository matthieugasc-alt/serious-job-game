# Team — Roles, Skills & Delegation Rules

## How to use this file

Before recommending delegation in a briefing, match the task to the right
person using the profiles below. Never delegate based on availability alone —
match on competence and scope. If no one fits, flag it as founder-only.

---

## Delegation decision tree

When recommending delegation in a briefing:

1. **Is it a founder-only decision?** (investor, board, strategic, contract
   signature, fundraising) → Matthieu only.
2. **Is it a pitch, demo, or marketing task?** → Lugan.
3. **Is it a first contact requiring scientific credibility?** → Thomas.
4. **Is it a new-hospital prospection / institutional intro (DG, DGOS, DSI,
   ARS, ministère) ?** → **Olivier Véran** (partenaire opérationnel
   prospection).
5. **Is it AP-HP or Vivalto clinical coordination?** → Lou.
6. **Is it terrain deployment, nursing training, or interim coordination?**
   → Hugo.
7. **Is it a dev/technical task or IA improvement?** → Bruno (→ Romain).
8. **Is it client integration (temporary)?** → Romain, but flag that this
   should eventually move elsewhere.
9. **Is it an organizational/planning task?** → Not Lugan, not Thomas.
   Consider Lou or escalate to Matthieu.
10. **Does it require contractual rigor?** → Matthieu only. No one else
    has this competence currently.
